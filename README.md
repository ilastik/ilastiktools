# ilastik carving tools

`ilastik_carving_tools` are used in the [Carving Workflow](https://www.ilastik.org/documentation/carving/carving) in ilastik.

Originally developed by [@DerThorsten](https://github.com/DerThorsten), maintained by the ilastik team.


**Note**: This package was originally called `ilastiktools` and renamed to `ilastik_carving_tools` mid 2026.
`ilastiktools` is still available via the `ilastik-forge` channel, whereas `ilastik_carving_tools` target `conda-forge`.
